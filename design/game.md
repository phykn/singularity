# 플레이와 화면

모바일에서 한 화면을 보며 번개의 성장과 궤도의 변화를 관찰한다. 정확한 수치는 [게임 규칙](gravity.md)과 [rules.json](rules.json), 공격 결합은 [스킬 기획](skills.md)을 따른다.

## 준비와 한 판

준비 화면은 블랙홀과 원형 궤도, SINGULARITY, START, 언어 선택으로 구성한다. 설명 문구·플레이 시간·성장 방침·선호 번개·최고 기록은 이 화면에 표시하지 않는다. 안내와 설정은 상단 아이콘으로 연다. 효과 줄임에서는 준비 화면의 궤도와 빛도 정지한다.

START 아래에는 한국어 / ENG / 中文 / 日本語를 둔다. 선택하면 카드·안내·설정·일시정지·결과와 접근성 이름까지 해당 언어로 바뀐다. 언어는 설정과 일시정지에서도 바꿀 수 있으며 진행과 열린 카드의 제한시간은 유지한다.

성장 방침이나 사전 빌드 선택은 없다. 성장 방향은 플레이 중 세 카드에서 선택한 스킬 조합으로 정해진다. 첫 강화부터 여덟 형태 모두 후보에 나올 수 있다. 이동·공격은 자동이며 입력 없이 진행하려면 8초 뒤 표시된 자동 후보를 기다린다. 제한시간과 후보는 개방 때 고정한다.

처치한 입자는 전자에게 에너지를 보내고, 놓친 입자는 중앙에 합쳐진다. 중앙 질량이 늘면 전자의 원이 안쪽으로 밀린다. 가속 선택은 속도와 지지 반경을 높인다. 이미 쌓인 질량이 없어지는 연출은 쓰지 않는다.

충돌 준비가 되면 전자와 준비 표시가 금빛으로 바뀐다. 준비된 충돌은 블랙홀 생성으로 이어진다. 미처 준비되지 못한 충돌은 작은 섬광과 소멸로 끝난다. 마지막 수렴은 남은 시간이 끝나면 시작하며, 그 전에 접촉하면 조기에 끝난다.

## 화면 배치

검은 단색 배경과 흰 글자, 청색 번개를 기본으로 한다. 격자, 장식용 코드, 전투 중 긴 설명을 추가하지 않는다. 전투의 좌우 여백은 16픽셀, 준비 화면은 24픽셀(작은 화면·가로 화면은 20픽셀)이며 기본 간격은 8·16·24픽셀을 사용한다.

| 영역 | 내용 |
| --- | --- |
| 상단 80픽셀 | 레벨, 공격력·공속·이속의 아이콘과 값, 일시정지, 에너지 비율과 남은 시간. 위험은 경고 아이콘, 준비 완료는 체크 표시 |
| 중앙 | 가장 넓은 전장. 접근 입자, 전자·번개, 중앙 응집, 현재 궤도와 희미한 최초 궤도 |
| 하단 72픽셀 | 번개 스킬 네 슬롯과 단계 점, 현재 레벨의 경험치 / 필요 경험치와 막대. 최대 레벨은 MAX |
| 선택할 때 | 전장 하단 위에 세 열 카드. 희귀도 이름·색, 자동 후보, 능력 이름, 짧은 변화, 움직이는 미리보기 |

전장 중심은 논리 좌표 (180,260)이며 그 중심의 360×360 영역을 가로·세로 동일 배율로 표시한다. 궤도는 모든 크기에서 원이고 반경의 변화만 표현한다. 빠르게 입자를 분해하면 추가 유입이 빨라져 다음 무리를 이어서 상대한다. 생성 가속은 별도 긴 안내나 팝업 없이 전장의 밀도와 공격으로 보여준다.

카드가 열려도 캔버스의 크기와 좌표는 유지한다. 평상시 작은 세로 화면에서도 전장이 높이의 70% 이상을 사용한다.

세로 320×568·360×640·375×812·430×932와 가로 568×320·812×375를 확인한다. 가로 화면에서는 전장을 왼쪽에, HUD와 선택·시작 영역을 오른쪽에 둔다. 터치 영역은 최소 44×44픽셀이다. 보조 문구 12픽셀, 카드 이름 14픽셀을 기준으로 하며 글자를 잘라서 맞추지 않는다.

## 알아볼 수 있는 변화

- 공격력: 번개의 중심선이 굵어지고 응집 입자의 체력이 더 크게 줄어든다.
- 공속: 기본 번개와 위성이 더 자주 발사한다.
- 가속: 실제 이동속도와 잔상이 변하며, 중력에 밀렸던 궤도가 부드럽게 펼쳐진다.
- 중앙 흡수: 입자가 중앙에 합쳐지고 짧은 파장이 번진다. 에너지 획득과 다른 색을 쓴다.
- 위험: 준비 에너지가 부족하고 중앙과의 여유가 작으면 안쪽 경계와 짧은 경고를 표시한다.
- 침입파: 3초 전에 바깥쪽 두 방향을 예고하고 그 위치에서 입자가 접근한다. 팝업과 주행 정지는 없다.
- 준비 완료: 에너지 목표에 도달하면 금빛과 짧은 문구로 알린다. 성공할 수 있는 충돌을 실패 경고로 표시하지 않는다.

전장은 반 해상도의 픽셀 캔버스로 그린다. 전자·작은 입자·응집 입자·위성은 Phaser CanvasTexture로 만든 도트 텍스처를 재사용하며, 글자·아이콘·카드 미리보기는 선명하게 유지한다. 응집 입자는 체력 비율을 네 점으로 보여준다. 작은 입자는 손상을 입었을 때 짧은 체력 선을 보여준다.

기본·분기·연타·관통 번개의 발사점은 현재 전자 위치를 따라가며 0.14초 동안 표시한다. 위성 번개는 실제 위성 위치에서, 연쇄는 맞은 입자에서 다음 입자로 이어진다. 파편과 범위 효과가 발사 번개를 밀어내지 않도록 효과 종류별 표시 수를 제한한다. 번개와 파편 효과의 표시 개수를 제한해도 입자 생성·피해·흡수 판정은 생략하지 않는다.

모든 타격에서 계산한 피해량을 기록한다. 소수 피해와 처치 타격의 초과 피해도 사용하며 가짜 치명타나 임의 배율을 붙이지 않는다. 숫자는 0.72초 동안 떠오르고 사라진다. 모델에서 최대 64개를 유지하고 Phaser의 Text 그룹을 재사용한다. 화면에는 최신 숫자를 우선해 서로 겹치지 않는 위치에 24개까지 표시한다. 효과 줄임은 12개까지 0.4초간 정지된 숫자로 표시한다. 정지 중에는 숫자의 수명도 멈춘다.

## 문구와 아이콘

한국어 문구는 [리그 오브 레전드 플레이 안내](https://www.leagueoflegends.com/ko-kr/how-to-play/)와 [와일드 리프트 게임 소개](https://wildrift.leagueoflegends.com/ko-kr/game-overview/)의 익숙한 게임 용어를 참고한다. 능력·분해·연결 대신 화면에서는 스킬·처치·연쇄를 쓰고, 카드에는 변화만 짧게 적는다. 자세한 설명은 도움말에 둔다. 자동 선택 표시에는 남은 초와 자동 선택을 함께 적어 레벨업 시간으로 오해하지 않게 한다.

조작과 스킬 아이콘은 [Lucide React](https://lucide.dev/guide/react)를 사용한다. 작은 HUD 아이콘도 실제 표시 크기에 맞는 선 두께를 유지한다. 스킬의 움직임과 범위 미리보기는 SVG로 표시하며 관통 선은 모든 단계에서 적을 통과한다.

## 충돌과 결과

충돌 상태에서 판정을 확정하고 3초 동안 중앙으로 감긴다. 질량이 전혀 없는 최종 수렴에서는 반대편 전자가 함께 중앙으로 들어온다. 성공하면 12초 동안 작은 암점이 커지며 입자와 궤도를 삼키고, 실패하면 3초 동안 섬광이 잦아든다.

결과는 성공/소멸, 시간, 레벨·누적 경험치·질량, 스킬 조합, 다시하기 / 새 게임을 표시한다. 처치 점수는 접힌 상세 기록 안에 둔다. 보유 조합에도 희귀도 이름과 색을 표시한다. 상세에는 시드·조기/최종 충돌·입자별 등장/처치/흡수/남은 수·기본 강화·최고 기록을 둔다. 블랙홀의 시각적 흡수는 전투의 중앙 흡수 수에 더하지 않는다.

## 정지와 복귀

일시정지는 주행, 공격 예약, 카드 개방·제한시간, 충돌과 결말 시계를 모두 멈춘다. 화면 이탈도 같은 시계를 멈추며 숨겨진 동안의 에너지와 이동을 계산하지 않는다. 화면 이탈 전 수동으로 멈췄다면 돌아와도 수동 정지를 유지한다.

정지 패널에서 사운드·시각 효과·언어를 바꾸거나 계속하기를 누를 수 있다. 그만하기는 한 번 확인한 뒤 같은 시드의 준비로 돌아간다. 중도 종료는 성공/실패 기록을 만들지 않는다.

다시하기는 동일한 시드로 돌아가 다른 카드 선택을 비교하게 한다. 새 게임은 새 시드를 사용한다. 두 경우 모두 경험치·질량·강화·선택·궤도를 초기화한다. 그만하기는 확인 후 진행 저장을 지우고 준비 화면으로 돌아간다.

진행은 1초마다, 시작·수동 선택·일시정지·화면 이탈·pagehide·freeze·결과 도달 때 브라우저에 저장한다. 새로고침이나 Android의 탭 재생성은 저장한 판을 자동으로 복원한다. 규칙 버전·시드·진행 틱·수동 선택·수동 정지·상태를 singularity.run.v7에 저장하고, Zod로 형식과 범위를 확인한 뒤 같은 고정 틱을 재생한다. 적·경험치·질량·예약 공격·열린 카드·희귀도·결말은 기존 엔진을 통해 복원한다. 숨김 정지는 새 페이지로 넘기지 않고 실제 화면 상태에 맞춘다.

화면 밖의 시간은 진행하지 않는다. 수동 정지는 새로고침 후에도 유지하며, 끝난 판은 같은 결과를 보여준다. 탭이 예고 없이 종료돼도 주기 저장으로 복원하고 마지막 저장 이후의 최대 약 1초는 유실될 수 있다. v6 저장은 원래 규칙을 선택해 같은 엔진에서 끝까지 진행하며, 성공적으로 저장한 뒤 예전 저장 키를 정리한다. 새 게임부터 v7 수치를 사용한다. v6보다 오래된 버전이나 잘못된 입력은 불러오지 않는다. 저장이 차단되면 짧은 안내를 표시하고 현재 판은 계속 진행한다.

## 설정과 기록

소리는 첫 방문에 꺼져 있다. 사용자가 켤 때 오디오를 활성화하고, 실패하면 다시 시도할 수 있는 짧은 안내를 표시한다. 효과 줄임과 기기의 동작 줄이기는 미리보기 애니메이션·잔상·파편·섬광을 줄인다. 입자의 위치·접근과 궤도 변화는 유지한다.

소리·효과 설정은 기존 critical-point.settings.v1을 유지하고, 언어는 singularity.language.v1에 저장한다. 기본 언어는 한국어이며 잘못된 저장값은 기본값으로 돌아간다. 최고 기록은 critical-point.record.v7에 별도로 저장해 이전 성장 규칙의 기록과 비교하지 않는다. 이어 한 v6 결과도 v7 기록을 덮지 않는다. 성공 여부 → 경험치 → 충돌까지 버틴 시간 순으로 비교하며 동률은 기존 기록을 유지한다. 저장이 막혀도 시작과 한 판 진행은 가능하다.
