# 중력 붕괴 규칙

v7 구현 기준, 2026-10-04. 실행 수치는 [rules.json](rules.json), 화면·정지·저장은 [플레이 기획](game.md), 공격 결합은 [스킬 기획](skills.md)이 소유한다. 현재 검증 결과와 실행 명령은 [README](../README.md)를 따른다.

## 한 판과 종료

전자는 자동으로 궤도를 돌며 입자에게 번개를 쏜다. 처치는 누적 경험치 E를, 중앙 도착은 질량 M을 늘린다. 이미 쌓인 질량은 사라지지 않는다. 공격 강화는 다음 흡수를 막고 가속은 같은 질량에서 궤도를 넓힌다. 이동·공격·카드 자동 선택만으로 한 판이 진행되며, 사용자는 세 카드 중 원하는 것을 직접 고를 수 있다.

| 항목 | 규칙 |
| --- | --- |
| 시작 | E=0, M=0, 레벨 1, 반경 132, 강화 0단계 |
| 주행 | 최대 585초. 정지·화면 이탈 시간 제외 |
| 조기 충돌 | 전자와 중앙 응집이 접촉하면 즉시 |
| 최종 충돌 | 585초에 강제 수렴 |
| 성공 | 충돌 진입 때 E≥23500이면 블랙홀, 미달이면 소멸 |
| 결말 | 충돌 3초 + 블랙홀 12초 또는 소멸 3초 |
| 한 판 | 성공 완주 600초, 실패 완주 591초. 조기 충돌은 더 짧음 |

화면은 한 판의 최대 10분을 기준으로 남은 시간을 표시한다. 충돌 뒤에는 남은 결말 시간을 표시한다. 결말에 들어가면 생성·공격·보상·카드 선택을 모두 종료한다. 미확정 카드와 예약 타격은 취소한다. 시간만으로 질량이나 능력치를 더하지 않는다.

## 입자와 후반 유입

중심은 논리 좌표 (180,260)이다. 입자는 반경 170에서 중앙을 향해 나선으로 이동한다. 입자와 전자의 직접 접촉은 피해를 주지 않는다. 작은 입자는 초당 17.5, 응집 입자는 11.25만큼 안으로 이동하며, 회전속도는 각각 0.12·0.08라디안이다.

| 구간(초) | 작은 HP / 묶음 | 응집 HP / 묶음 | 일반 간격 | 빠른 처치 간격 | 추가 가속의 적 수 조건 |
| --- | --- | --- | --- | --- | --- |
| 0–90 | 2 / 10개 | 8 / 2개 | 2.4초 | 0.8초 | 12개 미만 |
| 90–210 | 3 / 14개 | 16 / 3개 | 2.2초 | 0.75초 | 28개 미만 |
| 210–330 | 6 / 20개 | 38 / 4개 | 2초 | 0.65초 | 52개 미만 |
| 330–450 | 11 / 30개 | 74 / 6개 | 1.8초 | 0.55초 | 88개 미만 |
| 450–585 | 16 / 40개 | 130 / 8개 | 1.6초 | 0.45초 | 140개 미만 |

첫 세 묶음은 작은 입자 10개다. 이후 작은 묶음의 확률은 구간마다 90% / 60% / 90% / 50% / 75%다. 작은 입자는 모이고 응집 입자는 떨어져 들어온다. HP는 생성 때 정하며 구간 전환이 이미 나온 적을 강화하지 않는다.

90·210·330·450·540초의 침입파는 반대편 두 방향에서 작은/응집 입자 합계 12/2, 18/4, 24/4, 36/6, 48/8개를 추가한다. 각 방향의 기본 수에 배율을 곱해 반올림한다. 3초 전 진입 위치를 예고하며 주행과 카드를 멈추지 않는다.

작은 입자는 처치 경험치·흡수 질량 각각 1, 응집 입자는 각각 5다. 살아서 중심 거리가 중앙 반경과 자신의 외형 반경(작은 5, 응집 8)의 합 이하가 되면 흡수한다. 한 틱의 흡수 후보는 처리 시작 때의 중앙 반경으로 정하고 ID순으로 정산한다. 처치와 흡수는 서로 배타적이다. 개수 상한이나 시간 만료로 적을 삭제하지 않는다.

최근 2초 동안 처치 경험치 합이 8 이상이면 2초 동안 추가 유입을 활성화한다. 적 수가 표의 조건 미만일 때 다음 생성을 앞당기고 짧은 간격을 적용한다. 빠른 처치가 이어지면 활성 시간을 갱신한다. 적이 쌓이면 일반 간격으로 돌아가지만 이미 예약한 생성과 침입파는 유지한다. 표의 적 수는 가속 조건이며 전장 개수 상한이 아니다.

후반 작은 묶음은 초반의 네 배이고 일반 간격도 짧아진다. 빠르게 정리한 조합은 후반에 최대 약 0.45초마다 다음 무리를 맞는다. 추가 유입을 제외한 평균 제공 경험치는 약 7986이며, 실제 획득량은 처치와 추가 유입에 따라 달라진다.

점수는 처치 보상 × 10 × (1 + 처치 반경/170)을 반올림해 더한다. 흡수는 점수를 주지 않는다. 점수는 경험치·성장·난이도·결말에 영향을 주지 않으며 결과의 상세 기록에만 표시한다.

## 질량과 궤도

길이·속도는 논리 좌표 기준이다. 가속 단계 A는 0–5, 희귀도 배율 S는 1 / 1.2 / 1.45 / 1.8이다.

- 중앙 반경 C = 10 + min(24, 0.08M), 전자 충돌 반경은 4.
- 실제 속도 V = 150 × (1 + 0.30AS).
- 목표 반경 = clamp(132 + 12AS − 0.65M, 0, 132).
- 실제 반경 R은 목표를 향해 안쪽으로 초당 최대 4, 바깥으로 최대 6만큼 변한다.
- 각속도는 V/R이다. 원이 좁아지는 것과 실제 이속이 빨라지는 것은 다르다.
- 여유 H = R − C − 4. H≤0이면 충돌, H<24이고 경험치가 미달이면 위험이다.

M=100, 일반 A=0일 때 C=18, 목표 반경 67이다. 가속을 한 단계 고르면 속도 150→195, 목표 반경 67→79이며 다른 변화가 없으면 2초에 반경 12를 회복한다. 질량은 100 그대로다. M=170, A=0이면 목표 반경 21.5가 접촉 반경 27.6보다 작다. 접촉 전에 가속을 고르면 목표 반경 33.5로 회복할 수 있다.

가속을 고르지 않았다는 이유로 실패시키지 않는다. 충분히 요격하는 공격 조합도 성공할 수 있다.

## 경험치와 레벨 업

경험치는 소비하지 않고 처치 보상을 더할 때 레벨이 즉시 오른다. 별도 시간 조건은 없다. 최대 레벨은 26이고 최대 25회 스킬을 고른다. 정확한 누적 곡선은 rules.json의 levelXp다. 대표 문턱은 레벨 2:18, 3:85, 10:2080, 20:9980, 26:17600이다.

경험치 막대는 현재 레벨에서 모은 양 / 다음 레벨에 필요한 양이다. 누적 118이면 레벨 3, 막대는 33 / 125다. 최대 레벨에서는 MAX를 표시하고 추가 경험치는 충돌 준비에 보탠다. 위의 특이점 비율은 누적 경험치 / 23500이다.

레벨 자체는 능력치를 올리지 않는다. 세 카드 중 하나를 선택해야 효과가 적용된다. 열린 카드가 있는 동안 얻은 레벨과 초과 경험치는 유지하고, 확정하면 다음 대기 선택을 즉시 연다. 개방부터 8초 뒤 강조한 후보를 자동 선택한다. 정지·화면 이탈은 기한도 멈춘다. 카드 내용·희귀도는 개방 때 고정한다.

공격력은 2 + 단계×S, 공속 배율은 1 + 0.35×단계×S, 가속은 위의 속도·반경 식을 쓴다. 세 기본 강화는 각각 최대 5단계이며 네 번개 슬롯을 차지하지 않는다. 일반 최대 피해는 7, 공속은 2.75배, 이속은 375다. 전설 최대 피해는 11, 공속은 4.15배, 이속은 555다. 공속은 기본·위성의 남은 주기 비율을 유지해 다음 발사를 앞당기고 반복·흔적의 고정 주기는 바꾸지 않는다.

첫 세 후보는 여덟 형태에서 추첨하며 광역·갈래·연쇄를 최소 하나 포함한다. 이후에는 슬롯이 남는 미보유 형태, 5단계 미만의 보유 형태·기본 강화가 유효하다. 자동 후보는 위험할 때 미완성 가속, 그 외에는 홀수 선택의 형태·짝수 선택의 기본 강화부터 고른다. 두 형태까지 새 형태를 우선하고 이후 낮은 보유 단계부터 강화한다. 기본 강화의 동률은 공격력·공속·가속 순이다. 나머지에는 가능한 반대 범주와 무작위 후보를 넣는다.

희귀도를 독립 추첨한 후, 위험 대응 가속을 제외하고 자동 후보보다 희귀도가 두 단계 이상 높은 카드를 자동 후보로 앞에 둔다. 사용자는 어느 카드든 선택할 수 있다. 사전 성장 방침으로 후보를 제한하지 않는다. 슬롯 네 개와 트랙별 다섯 단계에서 유효 후보가 두 개 이하가 되려면 적어도 25회 강화해야 한다. 마지막 선택 직전은 최대 24회이므로 세 장이 유지된다. 엔진 검사는 네 형태·세 능력치의 모든 단계 조합과 실제 25회 선택을 확인한다.

## 같은 시각의 처리

렌더와 독립적인 60Hz 고정 틱을 쓴다.

1. 585초에 도달했다면 즉시 최종 충돌.
2. 카드 자동 확정 → 일반 묶음·침입파 생성.
3. 입자 이동 → 전자 각도 진행 → 만료 흔적 제거.
4. 예약 타격 → 흔적 피해 → 기본 발사 → 위성 → 새 흔적.
5. 살아 있는 입자 흡수 → 실제 궤도 갱신 → 접촉 충돌.
6. 주행 중이면 새 레벨의 카드를 개방.

죽은 입자는 같은 틱의 중앙 질량이 되지 않는다. 수동 입력은 기록한 틱에 적용한다. 정지·지난 카드 번호·기한 지난 클릭은 무시하며 기한 시각에는 자동 선택이 먼저다.

## 조정과 호환성

시드 10000–10199로 초반 체력 증가·후반 밀도·성장 곡선을 조정했다. 별도 40000–40899의 900판에서 192판(21.3%)이 성공했다. 이는 무입력 자동 선택의 결과이며 실제 사용자 승률은 별개다. 첫 변화 25초 이내, 최종 충돌 판의 최대 레벨 전 선택 공백 90초 이내, 성공 판의 마지막 강화 사용 30초 이상을 확인한다.

v6에서 저장한 판은 [v6-rules.json](v6-rules.json)의 원래 규칙으로 끝까지 재개한다. 새 게임부터 v7을 적용한다. 하나의 엔진에 판별 규칙을 전달하며 이전 엔진을 복제하지 않는다. v6 저장의 수동 조합과 최종 결과가 같고, 새 규칙도 정지·재로딩·결말 복원이 되는지 실행으로 검증한다.
