# SINGULARITY

전자가 자동으로 궤도를 돌며 번개로 적을 처치하는 모바일 한 페이지 게임입니다. 경험치를 모아 레벨을 올리고 세 스킬 중 하나를 골라 조합을 만드세요. 놓친 입자는 중앙에 쌓여 궤도를 좁힙니다. 충돌 전에 충분한 경험치를 모으면 블랙홀이 됩니다.

현재는 **v7 도트 전장·후반 밀도·25회 성장**입니다. 성공한 완주 판은 10분이며 중앙에 일찍 닿으면 먼저 끝납니다. React + Phaser + TypeScript + Vite에 Lucide React 아이콘과 Zod 저장 검증을 사용합니다. 상세 규칙은 [기획](plan.md)에서 확인합니다.

## 플레이

휴대폰에서 [고정 개발 주소](https://flyer-affirm-observer.ngrok-free.dev)를 열고 **START**를 누르세요. 아래의 **한국어 / ENG / 中文 / 日本語**로 언어를 고릅니다. ngrok 안내가 나오면 Visit Site를 누릅니다. 개발 PC·서버·터널이 실행 중이어야 접속할 수 있습니다.

- 이동과 공격은 자동입니다. 적을 처치해 경험치를 얻으면 바로 레벨이 오릅니다. 레벨업을 기다리는 별도의 시간 조건은 없습니다.
- 세 카드 중 하나를 고르거나 8초 뒤 표시된 자동 선택을 기다립니다. 성장 방침이나 사전 빌드 제한은 없습니다.
- 최대 레벨은 26이며 최대 25회 스킬을 고릅니다. 번개는 네 종류까지, 종류별 강화는 다섯 단계입니다. 공격력·공격 속도·가속은 별도 강화이며 레벨만으로 오르지 않습니다.
- 아래 경험치 막대는 현재 레벨에서 모은 양 / 다음 레벨에 필요한 양을 표시합니다. 위의 특이점 비율은 누적 경험치 목표 **23500**의 달성률입니다. 준비된 충돌은 블랙홀로 이어집니다.
- 번개가 맞으면 계산된 피해량이 숫자로 뜹니다. 공격력 강화와 소수 피해가 반영되며 적의 남은 체력보다 큰 마지막 타격도 그대로 표시합니다.
- 희귀도 추첨은 일반 65% / 희귀 25% / 에픽 8% / 전설 2%입니다. 높은 희귀도는 번개의 수·범위·강화 효과를 늘리고 한번 얻은 희귀도는 유지합니다.
- 후반에는 한 무리의 크기가 초반의 네 배로 늘고 유입도 빨라집니다. 빠르게 처치하면 추가 무리가 들어옵니다. 가속을 강화하면 이동 속도와 궤도가 회복됩니다.
- 일시정지에서 사운드·시각 효과·언어를 바꿀 수 있습니다. 화면을 떠나 있는 동안은 모든 게임 시간이 멈춥니다.
- 결과의 **다시하기**는 같은 시드, **새 게임**은 새 시드로 돌아갑니다. 점수와 최고 기록은 접힌 **상세 기록** 안에 있습니다.

도움말 아이콘에서 스킬의 설명과 단계별 수치를 확인할 수 있습니다. 첫 방문의 소리는 꺼져 있습니다.

진행은 매초와 중요한 입력·화면 이탈 때 자동 저장합니다. Android에서 탭이 새로 불러와지거나 새로고침해도 저장한 판을 이어 합니다. 수동 정지는 복원 후에도 유지합니다. **그만하기**를 확인하거나 재도전을 고르면 이전 진행을 지웁니다. 브라우저가 예고 없이 종료되면 마지막 저장 이후의 최대 약 1초가 유실될 수 있습니다. 저장이 차단되면 안내를 표시하고 현재 판은 계속할 수 있습니다.

업데이트 전에 저장한 **v6 판은 원래 규칙으로 끝까지 이어집니다**. 새 게임부터 v7을 사용하며 이전 규칙의 결과는 v7 최고 기록과 비교하지 않습니다.

## 개발

Node.js 24 이상이 필요합니다.

```powershell
npm ci
npm run dev
```

[로컬 화면](http://localhost:8081)을 엽니다. Vite는 0.0.0.0:8081을 사용하고 기존 ngrok은 같은 포트를 전달합니다. 터널이 종료됐다면 기존 계정에서 다음 명령으로 다시 시작합니다.

```powershell
ngrok http 8081 --url https://flyer-affirm-observer.ngrok-free.dev
```

개발 서버의 ?seed=1701은 저장된 판이 없는 경우 시작 시드를 지정합니다. window.__gameDebug로 시간 진행·경험치 주입·초기화를 할 수 있습니다. 제작 빌드에는 이 훅과 쿼리 시드 입력이 없습니다. 진행 복원은 규칙 버전·시드·수동 입력으로 같은 엔진을 재생합니다. 수치를 바꿀 때는 이전 규칙 파일과 저장 호환성을 함께 확인합니다.

범용 기능은 기존 라이브러리로 해결합니다. Phaser가 전장과 Text 그룹을 렌더하고, React가 UI를 구성하며, Lucide가 아이콘을 제공하고, Zod가 저장 데이터 형식과 범위를 검사합니다. 스킬 미리보기와 게임 규칙은 이 프로젝트가 소유합니다.

코드의 시작점은 [main.tsx](src/main.tsx) → [App.tsx](src/App.tsx)입니다. 바꿀 내용에 따라 다음 파일을 사용합니다.

| 변경 | 파일 |
| --- | --- |
| 게임 시계·음향·저장·화면 이탈 | [useGame.ts](src/useGame.ts), [storage.ts](src/storage.ts) |
| 적 밀도·경험치·단계별 강화 수치 | [rules.json](design/rules.json), [rules.ts](src/rules.ts) |
| 전투·중력·종료, 유효한 카드 후보 | [game.ts](src/game.ts), [growth.ts](src/growth.ts) |
| Phaser 생성·크기 변경·정리 | [GameCanvas.tsx](src/GameCanvas.tsx) |
| 전장·번개·피해 숫자, 도트 텍스처 | [scene.ts](src/scene.ts), [effects.ts](src/effects.ts), [pixels.ts](src/pixels.ts) |
| 화면·공통 아이콘·미리보기 | [App.tsx](src/App.tsx), [ui.tsx](src/ui.tsx), [SkillPreview.tsx](src/SkillPreview.tsx) |
| 네 언어 문구, 강화 수치의 표시 | [i18n.ts](src/i18n.ts), [skillText.ts](src/skillText.ts) |

[random.ts](src/random.ts)의 시드 난수는 생성·카드·희귀도마다 분리합니다. [geometry.ts](src/geometry.ts)의 좌표를 전투와 렌더가 함께 사용합니다. [v6-rules.json](design/v6-rules.json)은 이전 저장을 위한 수치이며 새 게임 조정용 파일이 아닙니다.

전장은 반 해상도에서 그리고 확대합니다. 도트 입자 텍스처는 Phaser CanvasTexture로 한 번 만들고 정수 배율로 재사용합니다. 번개의 첫 발사점은 현재 전자 위치를 따라가며 연쇄는 맞은 입자 사이에 연결됩니다. 글자·아이콘·카드 미리보기는 작은 화면과 네 언어에서 읽기 쉽도록 선명하게 유지합니다. 이미지 제작 도구나 추가 엔진은 필요하지 않습니다.

## 검증

```powershell
npm test
npm run check:design
npm run benchmark
npm run check:balance
npm run build
```

2026-10-04 기준 엔진·저장 검사 **40개**와 규칙 산술 검사를 통과했습니다. 네 번개와 세 기본 강화의 25만 개 이상 유효 단계 상태에서 서로 다른 세 후보를 검사하고, 512시드에서 첫 후보에 여덟 번개가 모두 등장하는지 확인합니다. 경험치 경계·초과량·즉시 레벨업·선택 대기열·다섯 단계의 실제 타격 범위·발사점·표시 한도·저장 복원·파손된 저장값과 기존 전투 판정을 포함합니다.

리팩토링만 적용한 시점에는 v6의 다섯 시드 × 여섯 시점, **30개 전체 엔진 상태가 변경 전과 같았습니다**. 이후 v7 수치 변경과 렌더 개선을 적용했습니다.

시드 1701~1730의 30판은 30/60fps에서 결과·이벤트·입자 정산이 같습니다. 첫 변화 25초 이내, 최대 레벨 이전 최종 충돌 판의 선택 공백 90초 이내, 성공 판의 마지막 강화 사용 30초 이상을 확인했습니다. 성공한 열 판의 마지막 선택은 **8:29~8:47**, 이후 전투는 58~76초입니다. 최대 레벨 이후 시간은 postMaxSeconds로 따로 기록합니다. 가속 없이도 공격 조합으로 시드 10000에서 성공합니다. 저장 복원 후의 다음 공격·이동·카드·최종 결과와 v6 수동 빌드의 원래 결과도 일치합니다.

### 난이도

목표는 **무입력 자동 플레이의 약 20% 클리어율**입니다. 카드·희귀도·실제 전투로 결말을 정합니다. 수동 선택과 실제 사용자 승률은 다를 수 있습니다.

경험치 곡선과 목표 23500은 시드 10000~10199로 조정했습니다. 별도 검증 시드 40000~40899의 **900판 중 192판, 21.3%**가 성공했습니다. 305판이 마지막 충돌까지 진행했고, 3분 이전 종료는 283판입니다. 전설을 선택한 판은 137/387, 전설 없는 판은 55/513가 성공했습니다. 이는 조합별 관측 결과입니다.

artifacts/balance.json에 엔진·규칙 해시와 시드별 결과를, artifacts/benchmark.json에 프레임 비교와 성장 시각을 저장합니다. 최대 관측 입자는 258개, 효과는 160개였습니다. 피해 숫자는 최대 64개를 유지하고 화면에는 겹치지 않는 최신 숫자 24개까지 표시합니다. 효과 줄임은 12개이며 표시 제한이 전투 판정을 바꾸지 않습니다.

### 화면·언어·복원

개발 서버를 실행한 상태에서 사용합니다.

```powershell
npm run check:browser
npm run check:languages
npm run check:resume
```

설치된 Chrome 또는 Edge를 사용합니다. 다른 실행 파일은 BROWSER_PATH, 다른 서버는 GAME_URL 환경변수로 지정합니다.

화면 검사는 세로 320×568·360×640·375×812·430×932와 가로 568×320·812×375에서 시작·세 카드·정지·종료·재도전·설정·두 결말을 실행합니다. 44픽셀 터치 영역과 화면 넘침을 확인합니다. 가장 좁은 세로와 가로에서는 **11종 × 5단계 × 4희귀도 = 220개 카드 변형**의 문구도 확인합니다.

언어 검사는 네 언어 × 여섯 화면에서 실제 언어 선택·수동 스킬 선택·정지·결과·언어 저장을 확인하며, 영어·중국어·일본어 카드도 좁은 화면에서 검사합니다. 복원 검사는 Pixel 7 화면을 모사한 Chrome에서 열린 카드·수동 빌드·수동 정지·결과의 재로딩과 렌더러 강제 종료 후 복귀를 실행합니다.

보고서는 artifacts/browser.json, artifacts/languages.json, artifacts/resume.json이며 화면은 artifacts/v7/에 저장합니다. 긴 판과 카드 변형은 개발 훅으로 진행합니다. 375×812의 후반 장면은 입자 180개에서 프레임 간격 중앙값 16.7ms, 95백분위 50ms였습니다. 데스크톱 Chrome의 모바일 화면 모사이며 실제 휴대폰 성능·발열·사운드·재미는 별도 확인이 필요합니다. README에서 시작해 실행·수치 수정·저장 호환·렌더 경로를 직접 점검했고, 별도 평가자의 독립 사용 검사는 수행하지 않았습니다.

시뮬레이터와 브라우저는 삼각함수의 미세한 계산 차이로 일부 처치 결과가 달라질 수 있습니다. 프레임 간격과 복원 비교는 같은 실행 환경에서 정확한 일치를 기준으로 합니다. 21.3%는 Node 시뮬레이터의 표본 결과입니다.

### 제작 빌드

```powershell
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 8082 --strictPort
```

별도 터미널에서 다음 명령으로 제작 화면의 시작, 디버그 훅 비노출, 재로딩 후 진행·수동 정지 복원을 확인합니다.

```powershell
$env:GAME_URL='http://127.0.0.1:8082'
node scripts/browser.mjs --production
```

실시간 검사는 개발 서버에서 node scripts/browser.mjs --realtime으로 실행합니다. 시간을 건너뛰지 않고 10분을 진행하며 같은 Chrome 엔진의 빠른 재생 결과와 비교합니다. 결과와 30초 간격 표본은 artifacts/realtime.json에 저장합니다. 현재 JavaScript 번들은 약 1.77MB, gzip 약 493KB이며 Phaser를 포함한 번들 크기 경고가 있습니다.

v7 시드 10000은 375×812 화면에서 실제 시계로 10분을 완주했고, 같은 Chrome 엔진의 빠른 재생과 전체 결과가 정확히 같았습니다. 25회 자동 선택과 최종 성공을 확인했습니다.

제작 빌드의 시작·디버그 훅 비노출·재로딩 후 수동 정지 복원을 통과했습니다. 고정 개발 주소에서도 Pixel 7 화면으로 실제 경험치 획득·수동 선택·ENG·정지·재로딩을 확인했습니다. 같은 주소의 v6 저장은 기존 수동 빌드·세 단계 표시·최종 결과를 유지했고, v7 최고 기록을 덮지 않으며 새 게임은 v7로 시작했습니다.
